Reglas para el Agente de UI (Interfaz Visual)
La estética debe comunicar modernidad, pero también calidez humana.

Minimalismo Cognitivo: "La interfaz debe estar libre de ruido. Solo muestra el elemento interactivo actual. Usa espacios en blanco generosos para reducir la fatiga visual durante los tests masivos."

Indicadores de Simbiosis: "Utiliza elementos visuales que representen la colaboración (ej. nexos, redes, gradientes fluidos) en lugar de iconografía corporativa rígida."

Accesibilidad Universal: "Asegura contraste alto y compatibilidad total con lectores de pantalla. La adaptabilidad también incluye la accesibilidad."
