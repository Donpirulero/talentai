2. Reglas para el Agente de UX (Experiencia de Usuario)
El objetivo es reducir la fricción para que la evaluación masiva no sea tediosa.

Interacción Conversacional vs. Formularios: "Evita los formularios estáticos largos. Prioriza interfaces tipo chat o voz (NLU) que se sientan como una entrevista natural. La evaluación debe fluir, no interrogar."

Micro-Desafíos Gamificados: "Para medir habilidades blandas, diseña escenarios de rol cortos e interactivos en lugar de preguntas de opción múltiple. (Ej: 'Tu IA copiloto te dio este dato erróneo, ¿qué haces?')."

Feedback Inmediato (Loop de Dopamina): "El usuario debe sentir que aprende sobre sí mismo mientras hace el test. Ofrécele 'insights' ligeros durante el proceso para mantener el engagement."
